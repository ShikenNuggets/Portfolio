**Team:** Solo
**Type:** Game Engine (Personal)
**Timeline:** June 2022 – Present
**Tech:** C++ / OpenGL / Git

[GadgetEngine](https://github.com/ShikenNuggets/GadgetEngine) started as a brand new game engine that built on everything I learned in [Roof Toppers and the PizzaBox game engine](#roof-toppers) while expanding in new directions.

More recently it's served as a test bed for new features in my [GadgetCore](https://github.com/ShikenNuggets/GadgetCore) library, which features reusable, decoupled, platform-agnostic components for use in game and game-adjacent projects. The primary goal of this library was to minimize boilerplate when starting up new projects.

I also used the engine for a [game jam in 2024](#whbg).
